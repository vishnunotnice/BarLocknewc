# BarLock Client Assessment Form

Static GitHub Pages version of the BarLock client assessment form.

## Publish

1. Open **Settings → Pages** in this repository.
2. Set **Source** to **GitHub Actions**.
3. Wait for the Pages workflow to finish.

The form will be available at:

https://vishnunotnice.github.io/BarLocknewc/

The form sends responses to the BarLock API at `https://vishnu.taile648e2.ts.net`. The home server, Tailscale HTTPS/Funnel, Ollama/Gemma, and Supabase must remain available for submissions to be saved.
